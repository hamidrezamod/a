# لایه انیمیشن و ترنزیشن

این پوشه از ابتدا برای **ترنزیشن‌های اختصاصی و پری‌لودر** آماده شده است، اما هیچ حرکتی از خودش اختراع نمی‌کند.

## وضعیت فعلی

- `transitions.js`: فهرست ترنزیشن‌ها. فعلاً فقط یک ترنزیشن ساده با نام `fade` وجود دارد.
- `useDetailTransition.js`: وضعیت باز/بسته شدن پاپ‌آپ را به حالت‌های `closed → entering → open → leaving` تبدیل می‌کند.

## بعداً چطور ترنزیشن اختصاصی اضافه کنیم؟

1. در `transitions.js` یک ترنزیشن جدید بساز (مثلاً `cinematic`) و قلاب‌های `beforeOpen` / `afterOpen` / `beforeClose` / `afterClose` را پر کن.
2. در `src/components/overlay/OverlayProvider.jsx` مقدار `transitionName` را به نام ترنزیشن جدید تغییر بده.

هیچ کامپوننت محتوایی (کارت‌ها، بخش‌ها، مقاله) نیاز به تغییر ندارد.

## پری‌لودر

پری‌لودر بعداً به‌عنوان یک لایه مستقل با `--z-preloader` (بالاترین لایه) کنار `DetailOverlay` اضافه می‌شود؛
محل قرارگیری آن در `App.jsx` مشخص و آماده است.
