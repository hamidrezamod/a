# فونت فارسی — جای خالی

این پوشه عمداً خالی است تا وقتی فونت فارسی نهایی را می‌فرستی.

## چطور اضافه کنم؟

فایل‌های فونت (فرمت `woff2` توصیه می‌شود) را داخل **همین پوشه** بگذار و نامشان را
با وزن فونت مشخص کن:

```text
src/assets/fonts/persian/
├─ vazirmatn-300.woff2
├─ vazirmatn-400.woff2
├─ vazirmatn-500.woff2
└─ vazirmatn-700.woff2
```

قاعده نام‌گذاری: `هرنامی-وزن.woff2` — وزن‌های مجاز: 300، 400، 500، 600، 700
(برای حالت ایتالیک: `هرنامی-400-italic.woff2`)

تمام. سایت خودش فونت را می‌شناسد و متن‌های فارسی (مقاله‌ها) با آن نمایش داده می‌شوند.
تا زمانی که این پوشه خالی است، از فونت‌های جانشین (Tahoma و ...) استفاده می‌شود و
هیچ خطایی هم رخ نمی‌دهد.
