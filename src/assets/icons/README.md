# آیکون‌ها — وضعیت فعلی: جای خالی با نمونه‌های موقت

آیکون‌های SVG اصلی هنوز ارسال نشده‌اند. برای اینکه سایت ناقص به‌نظر نرسد،
برای هر آیکون یک **نمونه ساده و تمیز** ساخته شده است.

## جایگزینی با آیکون‌های اصلی

فقط فایل SVG را با **همین نام** داخل این پوشه بگذار (نسخه قبلی را جایگزین کن):

| نام فایل | کجا استفاده می‌شود |
| --- | --- |
| `phone.svg` | آیکون تلفن در بخش تماس |
| `mail.svg` | آیکون ایمیل در بخش تماس |
| `instagram.svg` | اینستاگرام (تماس و پادکست) |
| `linkedin.svg` | لینکدین در بخش تماس |
| `dribbble.svg` | دریبل در بخش تماس |
| `letterboxd.svg` | لترباکس در بخش تماس |
| `castbox.svg` | لینک کست‌باکس در بخش پادکست |
| `vimeo.svg` | آیکون ویمیو زیر متن فیلم کوتاه |
| `google-drive.svg` | آیکون گوگل‌درایو زیر متن فیلم کوتاه |
| `menu.svg` | (برای منوی موبایل در مرحله بعد) |
| `play.svg` | دکمه پخش روی تصویر فیلم |
| `close.svg` | دکمه بستن پاپ‌آپ مقاله/تئاتر |
| `arrow-down.svg` | فلش پایین هیرو |
| `arrow-up-right.svg` | فلش لینک‌ها |

## نکته‌های فنی

- SVGها به‌صورت **inline** بارگذاری می‌شوند (نه به‌صورت تصویر)، پس رنگ‌شان با متن هماهنگ می‌شود.
- در SVG از `fill="currentColor"` یا `stroke="currentColor"` استفاده کن تا رنگ خودکار تنظیم شود.
- اگر فایل آیکونی وجود نداشته باشد، سایت خطا نمی‌دهد؛ در رزومه به‌جایش برچسب متنی و در بقیه محل‌ها فضای خالی نمایش داده می‌شود.
- اندازه‌ها با استایل کنترل می‌شوند، پس ابعاد داخلی SVG اهمیت زیادی ندارد (کادر ۲۴×۲۴ توصیه می‌شود).
